
## 🌟 项目简介

这是一个基于 **Java + SpringBoot + Vue + MySQL** 构建的完整本科实践教学管理系统，功能持续优化中...

### 🧩 功能模块一览

- 用户登录、注册（管理员·教师·学生三角色）
- 实训项目管理（校内名称·实训目标·实训内容）
- 实训报告管理（学生上传·报告率统计）
- 实训成绩管理
- 日程安排管理
- 学生评价管理
- 自主申请管理（教师审核）
- 实训单位管理
- 实训鉴定管理（教师审核）
- 校外实训成绩管理
- 校内实训参与情况统计
- 校外实训打卡情况统计
- 学生、教师、管理员管理
- 个人中心、修改密码

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置
- **Java**: JDK 1.8  
- **MySQL**: 8.0.41  
- **Node.js**: 16.20.2  

⚠️ *温馨提示：版本不一致可能导致依赖冲突或启动失败。*

### 🛠️ 开发工具推荐
- **后端开发**: IntelliJ IDEA 2022+  
- **前端开发**: VS Code  
- **数据库管理**: Navicat / DBeaver / MySQL Workbench  ...
